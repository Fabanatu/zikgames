Build a complete mobile-first Nigerian game portal using HTML, CSS, JavaScript, PHP, and MySQL.

The platform should be a lightweight, fun, addictive game portal where users can log in with their phone number and access five simple games. The design should feel modern, colourful, fast, youthful, and suitable for the Nigerian audience.

The portal name can be: FabGames.

Core Requirement:
Users do not register directly on this portal. Registration/subscription happens from an external source. When a user enters their phone number, the system should call an external API endpoint to check if the user has an active game token/subscription. If the API confirms the user is active, allow login and create a local session. If not active, show a message telling the user to subscribe/sign up first.

Technology:
Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL
Must be fully mobile responsive
Must work well on low-end Android phones
Use clean code structure
Use AJAX/fetch for API calls where needed
Use PHP sessions for login
Use MySQL for storing users, game scores, admin data, push tokens, and reports

Pages Needed:

1. Landing Page
   Create a beautiful landing page with:

* Hero section
* Game portal name
* Short description
* “Join / Login” button
* Preview of the 5 games
* Nigerian-style fun visuals
* Mobile-first layout
* Clear call-to-action

2. Login Page
   User enters phone number in Nigerian format, example: 08012345678.
   When submitted:

* Validate phone number
* Call external token-check API
* If active, log user in
* If inactive, show “You need to subscribe before playing”
* Store user phone number locally if not already stored
* Start user session

Example external API logic:
POST to: https://your-api-endpoint.com/check-token
Payload:
{
"phone": "08012345678"
}

Expected success response:
{
"status": true,
"active": true,
"message": "User active"
}

Expected failed response:
{
"status": false,
"active": false,
"message": "No active token"
}

3. User Dashboard
   After login, users should see:

* Welcome message
* Five game cards
* High score
* Last played game
* Total games played
* Leaderboard preview
* Notification prompt permission
* Logout button

Five Games To Build:

Game 1: Zombie Shooter
A simple tap-to-shoot game.

* Zombies move toward the player
* User taps/clicks to shoot
* Score increases per zombie killed
* Game ends when zombie reaches player
* Increase speed over time
* Save score

Game 2: Bubble Shooter
A simple bubble matching game.

* User shoots coloured bubbles
* Match 3 or more to clear
* Score increases per cleared bubble
* Simple levels
* Save score

Game 3: Fruit Slice
A fruit slicing game.

* Fruits move/fly on screen
* User swipes or drags to slice
* Avoid bombs
* Score increases per fruit sliced
* Game ends after 3 missed fruits or bomb hit
* Save score

Game 4: Stickman Shooter
A simple side-view shooting game.

* Stickman player shoots incoming enemies
* User can move left/right
* Tap shoot button
* Enemy waves increase
* Save score

Game 5: Danfo Dodge / Naija Traffic Runner
A Nigerian-themed avoiding game.

* Player controls a small character or danfo-style avatar
* Obstacles come from top/bottom or forward
* Player moves left and right to avoid obstacles
* Obstacles can include potholes, danfo buses, okadas, market carts, roadblocks
* Game gets faster over time
* Score increases based on survival time
* Save score

Game Design Requirements:

* All games should be simple and playable inside the browser
* Use HTML5 Canvas for games
* Mobile controls must be smooth
* Games should have start, pause, resume, restart, and exit buttons
* Display current score and high score
* Add sound toggle
* Add vibration feedback where supported
* Save score to database after each game ends
* Keep games lightweight and fast

* Admin can send notifications to all users
* Admin can send notification to a single phone number
* Admin can send notification to users who played a specific game
